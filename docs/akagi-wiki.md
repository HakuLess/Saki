# Akagi 项目

## 项目地址
https://github.com/shinkuan/Akagi

## 项目概述
Akagi是一个支持多个麻将平台（雀魂、天凤、麻雀一番街、天月麻将）的实时分析工具，能够使用自定义的AI模型实时分析对局并给出建议。项目内建Mortal AI作为示例模型。

## 核心功能

- 实时分析麻将对局
- 支持多个平台：
  - 雀魂 (Majsoul)
  - 天凤 (Tenhou)
  - 麻雀一番街 (RiichiCity)
  - 天月麻将 (Amatsuki)
- 支持多种游戏模式：
  - 四人麻将
  - 三人麻将
- 支持多种AI模型：
  - 内置模型
  - 在线服务器模型
  - 自定义模型
- 自动打牌功能（仅Windows版本且ot_server运行时可用）
- 文本用户界面 (TUI)

## 网络请求拦截机制

Akagi使用MITM（Man-In-The-Middle）代理技术来拦截和分析麻将游戏的网络通信：

1. **MITM代理服务器**：
   - 在本地启动代理服务器（默认127.0.0.1:7880）
   - 安装MITM代理证书到系统信任存储
   - 使用Proxifier等工具将游戏客户端流量重定向到MITM代理

2. **协议解析**：
   - 解析游戏特定的网络协议
   - 提取游戏状态、手牌和其他相关信息

3. **AI分析**：
   - 将解析的游戏数据传递给AI模型
   - 获取AI的建议和分析结果

4. **实时显示**：
   - 在TUI界面上显示游戏状态和AI建议

## 技术实现

- 使用Python 3.12开发
- 使用mitmproxy库实现网络代理功能
- 基于Mortal模型和MJAI协议进行AI分析
- 使用Textual库实现TUI界面

## 在Kotlin中实现类似功能的考虑

将Akagi的MITM代理功能移植到Kotlin/KMP环境需要考虑：

1. **代理服务器实现**：
   - 使用Ktor或Netty实现HTTPS代理服务器
   - 处理证书生成和安装

2. **协议解析**：
   - 实现雀魂等平台的协议解析器
   - 使用Kotlin序列化库处理JSON/Protobuf数据

3. **跨平台兼容性**：
   - 桌面平台：使用系统API配置代理
   - 移动平台：可能需要VPN API或WebView拦截

4. **UI实现**：
   - 使用Compose Multiplatform创建现代化UI
   - 实现游戏状态和手牌的可视化显示

## 使用方法

1. 安装MITM代理证书
2. 配置Proxifier将游戏流量重定向到代理
3. 选择合适的AI模型
4. 启动MITM代理服务器
5. 开始游戏，实时查看分析结果
