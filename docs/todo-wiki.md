# Saki 项目实现计划与技术栈

## 技术栈选择

### 核心框架
- **Kotlin Multiplatform (KMP)** - 用于跨平台开发
- **Compose Multiplatform** - 用于构建现代化UI
- **Ktor** - 用于网络代理服务器实现

### 特定平台技术
- **Windows**
  - **JNA (Java Native Access)** - 用于Windows进程和窗口操作
  - **Windows Input Simulator** - 用于键盘和鼠标输入模拟
  - **System Proxy API** - 用于代理配置

- **通用技术**
  - **Protobuf** - 用于解析雀魂网络协议
  - **Kotlin Coroutines** - 用于异步编程
  - **Kotlin Flow** - 用于状态管理

### AI模型集成
- **ONNX Runtime** - 用于本地模型推理
- **gRPC** - 用于与在线模型API通信
